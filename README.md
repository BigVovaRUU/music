# Тихий кадр

Минималистичное Chrome-расширение для фоновой музыки во время чтения манги. Пользователь добавляет локальные аудиофайлы, выбирает трек и может закрыть popup: музыка продолжит играть в фоне и повторяться без паузы через Web Audio.

## Возможности

- локальная библиотека треков в IndexedDB;
- фоновое воспроизведение после закрытия popup;
- бесшовный loop одного трека через `AudioBufferSourceNode`;
- play/pause, предыдущий/следующий трек, перемотка и громкость;
- включение и выключение повтора;
- никаких загрузок в облако — музыка остаётся на устройстве.

## Установка в Chrome

1. Откройте `chrome://extensions`.
2. Включите «Режим разработчика».
3. Нажмите «Загрузить распакованное расширение».
4. Выберите эту папку проекта.
5. Закрепите «Тихий кадр» на панели браузера.

## Структура

- `popup.html`, `popup.css`, `popup.js` — интерфейс расширения;
- `service-worker.js` — создание фонового offscreen-документа;
- `offscreen.html`, `offscreen.js` — Web Audio проигрыватель;
- `db.js` — локальное хранение аудиофайлов;
- `assets/` — сгенерированные иконки и обложка;
- `design/popup-concept.png` — принятый визуальный концепт.
